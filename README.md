# CityWalk

CityWalk — веб-сервис для создания индивидуальных прогулок по Астане.

## Как запустить

1. Дважды откройте `start-citywalk.cmd`.
2. Перейдите на `http://localhost:8000`.
3. Разрешите доступ к геолокации, если хотите начать маршрут от себя.
4. После изменений обновляйте страницу через `Ctrl + F5`.

Если команда не запускается, проверьте, установлен ли Node.js. Сервер использует порт `8000`.

## Что умеет проект

- определять местоположение пользователя;
- показывать точку пользователя на карте;
- искать места рядом с геолокацией или выбранным районом;
- фильтровать кафе, архитектуру, парки и места для фотографий;
- выбирать несколько мест и строить маршрут;
- выбирать пеший, автомобильный или автобусный режим;
- показывать расстояние и примерное время маршрута;
- отображать популярные места Астаны с описаниями и фотографиями Wikimedia;
- сохранять заметки, имя и аватар в профиле;
- переключать светлую и тёмную тему;
- показывать текущую погоду, ветер, рассвет и закат.

## Используемые открытые сервисы

- Leaflet + OpenStreetMap — карта и базовые объекты;
- Overpass API — поиск мест рядом с координатами;
- Nominatim — поиск района или точки по названию;
- OSRM — дорожная геометрия маршрута;
- Open-Meteo — погода без API-ключа;
- Wikipedia/Wikimedia Commons — описания и фотографии популярных мест.

## Важно

Время автобуса рассчитывается ориентировочно: для точных маршрутов, остановок и расписания потребуется отдельный транспортный API Астаны. Данные OpenStreetMap могут обновляться с задержкой.
